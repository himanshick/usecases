Planogram automation: end-to-end architecture (CPG, MPG, SAP XREF)

Monthly batch on Azure. SharePoint input, ADF orchestration, Azure SQL rules engine, human approvals, RPA upload to SAP.

1Trigger and ingest

SharePoint Online

Business input
  • Folder per month: CPG/, MPG/, Common/
  • Library columns: Status, RunId
  • Folder locked after Ready is clicked

Ready / Start button

Power Automate, "For a selected file"
  • Checks manifest of required files
  • Sets Status = Submitted
  • HTTPS call to ADF createRun (Entra app / managed identity)
  • Fallback: _READY.flag file trigger

ADF master pipeline

Orchestrator
  • Generates RUN_ID (RUN_YYYYMM_nnn)
  • Guard: one active run per month
  • Params: month, folder, triggeredBy, fromStep
  • Writes ctl.pipeline_run

Copy to ADLS Gen2

Frozen package
  • raw/YYYY/MM/RUN_ID/CPG, MPG, PDFs, Reference
  • Immutable (WORM) policy, lifecycle tiering
  • file_registry: name, size, rows, checksum

Snowflake

CPG / SAP reference data
  • ADF Snowflake connector copy
  • Snapshot into ref.* per RUN_ID
▼ package frozen, run status = INGESTED

2CPG processing (Azure SQL)

Staging load

ADF Copy, bulk insert
  • Excel from ADLS into stg.* by RUN_ID
  • Parallel copies, batch 100k rows
  • Row count reconciled to file_registry
  • Clean + standardise in set-based SQL

Business rules Q1-Q19

Stored procedures, ADF ordered
  • Item link, monthly changes, discontinued, new items
  • Discontinued / substitute replacements, POG updates, DN27
  • Order from ctl.processing_step dependencies
  • Set-based only, no cursors; logs rows in/out

Candidate results

cpg.* tables
  • Planogram Master (candidate)
  • Monthly New Item (candidate)
  • DN27 (candidate)

Azure SQL Database

Processing engine
  • Scale up before run, down after (ADF Web activity)
  • Clustered columnstore on large stg tables
  • Indexes on join keys (item, POG, SOG)
▼ validation stored procedures run

3CPG validation and approval (human in the loop)

Validation

Stored procedures
  • Missing items, invalid codes, invalid replacements
  • Duplicates, POG inconsistencies, rule checks
  • Writes validation_result and exception

Exception review

Power Apps over SQL views
  • Exceptions only, never 70k rows by hand
  • Server-side filter and paging
  • Fix or resolve with reason, then revalidate (validation step only)

Approval gate

Teams adaptive card / Approvals
  • Summary: row counts, exception count, delta vs last month
  • ADF Webhook activity waits for callback (timeout 7 days)
  • Decision, user, time into approval_audit

Generate 3 CPG files

ADF Copy from SQL
  • Planogram Master Data
  • Monthly New Item
  • DN27
  • Saved to outputs/CPG with checksum
▼ status = CPG_APPROVED

4Handoff to external team

Notify

Power Automate to Teams / email
  • Send secure link to SharePoint Outbound/RUN_ID, not attachments (60-70k-row files exceed mail limits)
  • Read-only access for the team

Run state

Status = AWAITING_TEAM
  • Pipeline ends, nothing runs while waiting
  • Scheduled flow sends SLA reminders

External team

Processes the 3 files
  • Returns processed files
  • Business uploads them to SharePoint (MPG/, Common/)
▼ second upload and "Ready for MPG" button

5MPG ingest and processing

Ready for MPG button

Power Automate
  • Validates RUN_ID exists and CPG is approved
  • Manifest: Product_Listings, SOG_PDFs, Category_Adjustments
  • Calls ADF MPG pipeline with same RUN_ID

Copy to ADLS (frozen)

Same run folder
  • MPG/ and PDFs/ added, then locked
  • file_registry updated

Excel / CSV path

ADF Copy
  • Bulk load to stg.mpg_*, 60-70k rows per file
  • Row-count reconciliation

PDF path

Document Intelligence + Azure Function
  • Batch async extraction: item number, description
  • Durable Function (Flex Consumption / Premium) normalises output
  • Low confidence goes to exceptions

Business rules Q1-Q33

Stored procedures, ADF ordered
  • Monthly sets, category processing, largest set
  • Planogram processing, label construction, item counts
  • Validation and export generation
▼ MPG validation stored procedures run

6MPG validation, approval and XREF

Validation

Stored procedures
  • Invalid item status, SOG data, description
  • POG mismatches, item count checks

Review and approval

Same pattern as CPG
  • Power Apps exceptions, Teams approval card
  • ADF Webhook waits, approval_audit logged

Generate SAP XREF file

Single output
  • Schema-validated, row count + hash recorded
  • Saved to outputs/MPG in ADLS
▼ status = MPG_APPROVED

7SAP upload and close

RPA upload

Power Automate Desktop, unattended
  • Cloud flow queues the job to a bot VM
  • Credentials from Key Vault
  • Retries, screenshots on failure
  • Reconcile SAP record count to XREF

SAP and label printing

Existing downstream process
  • XREF loaded, labels printed

Close run

ADF + Power Automate
  • Status = COMPLETED
  • Notify stakeholders, archive package

Scale: 60-70k rows per Excel

  • Never loop rows in Power Automate or Logic Apps
  • ADF Copy bulk loads; SQL does all transforms set-based
  • Stage by RUN_ID, drop or archive after retention
  • Large Excel is memory heavy: optionally convert to CSV/Parquet in the ingest step
  • Load-test at 3x volume before go-live

Control and audit tables

  • ctl.pipeline_run, file_registry, processing_step
  • validation_result, exception, approval_audit
  • ctl.config (rule toggles, thresholds, approvers)

Security

  • Entra ID RBAC, managed identities, no secrets in flows
  • Key Vault for keys and connection strings
  • Private endpoints, ADF managed VNet integration runtime
  • SharePoint permissions by role

Monitoring

  • Azure Monitor and Log Analytics, RUN_ID on every log
  • Alerts on failure, long run, approval pending
  • Run status dashboard (Workbook or Power BI)

Reliability

  • Idempotent steps, restart from any step with fromStep
  • Retries with backoff, failures raise alerts
  • Point-in-time restore for SQL, geo-redundant ADLS

DevOps

  • Bicep/Terraform infrastructure as code
  • ADF Git integration, CI/CD to Dev, UAT, Prod
  • SQL via DACPAC, tSQLt tests per rule (Q1-Q33)
